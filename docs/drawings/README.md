# Drawings

Every diagram on the site is an Excalidraw scene in this directory, generated by a script in
`_tools/` (`d01_what_is.py` writes `d01_what_is.excalidraw`). The `.excalidraw` file is the
source of truth: open it on excalidraw.com or in the VS Code Excalidraw extension. The SVGs under
`docs/assets/drawings/<id>.paper.svg` and `<id>.dark.svg` are exports, restyled to the site's
tokens (fonts embedded, one green accent, both colour schemes), and are committed so the build
needs no browser.

    cd docs/drawings/_tools && npm i && python3 -m playwright install chromium
    python3 d01_what_is.py        # rebuild one scene from its script
    python3 render.py             # export every scene to docs/assets/drawings
    python3 render.py --check     # exit 1 when a committed SVG does not match its source
    python3 preview.py ~/shots    # PNG of every export, both schemes, for a human look

Rules: roughness 0, 1px strokes, 8px radius, no shadows; one accent element per drawing; no em or
en dashes; every label word appears somewhere in `docs/**/*.md`.
