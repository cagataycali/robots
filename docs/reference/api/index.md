Heavy names are lazy: `import strands_robots` does not import torch, lerobot, numpy or mujoco. The first attribute access (`strands_robots.Robot`) triggers the real import and raises `AttributeError` with the missing dependency named when an extra is not installed.

The pages are generated by mkdocstrings from the source tree with static analysis, so they never drift from the code. Signatures show the defaults the code carries. For the tool catalog with action lists see [Tools](../tools.md); for environment variables see [Configuration](../configuration.md).
