## Hardware

**lerobot.** `Robot("so100", mode="real", driver="lerobot")` builds lerobot's `so100_follower` with `pip install 'strands-robots[lerobot]'`; `port=` is the serial device, `cameras=` the lerobot camera dict.

**`FeetechDriver`** (the default for this robot) speaks Feetech STS/SMS serial bus: [port, SDK, kwargs and checks](../learn/hardware/drivers.md#feetechdriver).
