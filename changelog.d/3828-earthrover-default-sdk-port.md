### Fixed: `Robot("earthrover", mode="real", driver="strands")` with `port=` omitted now reaches a stock earth-rovers-sdk. The driver's default SDK URL was `http://localhost:8001`, a port the vendor's SDK has never served; it is now `http://localhost:8000`, the port the SDK's Dockerfile binds and every SDK example uses, so `connect_eagerly()` no longer reports the SDK unreachable on a default install.
