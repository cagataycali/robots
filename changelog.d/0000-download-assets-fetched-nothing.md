### Fixed: a `download_assets` call that fetched nothing is no longer a success

`download_assets(action="download")` returned `status="success"` with `Downloaded: 0, Skipped: 0, Failed: 0` for every way of fetching nothing, so a typo read as a completed download. An unknown `robots=` name was only a `logger.warning` inside `download_robots`, a failed clone only an itemized line, and a selection matching no robot at all - what an unmatched `category=` produces - reported the same three zeros. `download_robots` now carries `unknown_names` on every return path, and the tool grades its verdict on that list, on `failed`, and on an empty selection. The text under those verdicts printed `Method: ?` and `Assets: ?`, because a result that never reached a download carries neither key; it now renders the library's own message instead.
