### Fixed

- **training**: every backend that reads `TrainSpec.save_freq` now reports a cadence it cannot honor, instead of returning an empty list - which `Trainer.validate`'s contract defines as "the spec is launchable". The field reaches four destinations that each require a genuine `int`, and none of them said so. The in-process LeRobot path assigns it to `cfg.save_freq`, which lerobot hands straight to `should_save_checkpoint(step, save_freq, total_steps)` - `(save_freq > 0 and step % save_freq == 0) or step == total_steps` - with no parser in between, so `save_freq=True` was a modulus of one and wrote a full checkpoint at **every optimizer step** (9999 of them in a 10 000-step run that asked for 9), `2.7` / `nan` / `inf` never satisfied `step % cadence == 0` for an integral step and so silently became the *disabled* mode, and `"5000"` raised `TypeError` from the comparison itself, inside the training loop after the dataset and model had loaded. The argv route decodes the same field with draccus and refuses `True` / `2.7` / `5000.0` / `nan` / `inf` while accepting the token `"5000"` renders - so the two LeRobot routes disagreed about the same spec, which `TrainSpec.extra` already forbids for its own values ("one spec means one run whichever path the backend takes"). GR00T's `--save_steps=`, Cosmos's `checkpoint.save_iter=` and SageMaker's JSON-encoded hyperparameter (where `nan` and `inf` travel as the non-JSON `NaN` / `Infinity`) each failed differently again, or not at all until the run had started. The cadence is now checked against the shared `step_cadence_error` domain that `lerobot_train` holds the same field to, so the wrapper and the wrapped pipeline cannot diverge. The **floor is deliberately not part of this domain**: lerobot documents a non-positive `save_freq` as "disables periodic saving" and `should_save_checkpoint` implements it, so `0` and a negative are still accepted and still select the single-final-evaluation fallback. A backend that does not read the field still reports nothing about it.
