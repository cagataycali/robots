### Added: `create_policy("rl")` loads an rsl_rl run, one `model_<n>.pt`, or a HuggingFace repo id

`checkpoint_dir` now takes what Isaac Lab leaves behind, not only the `policy.pt` + `policy_meta.json` pair a strands trainer writes: an rsl_rl run directory (its newest `model_<n>.pt`), a path to one such file, or a Hub repo id (`owner/name`, `hf://owner/name`, `owner/name@revision`) holding either shape. The rsl_rl actor is converted once into `<run>/strands_policy/` and reused while newer than the model; `action_names` from a `record.json` beside it bind the actions when their count matches, so the policy answers named actions without a robot. A repo that cannot be downloaded is the provider's `RuntimeError` verdict; a directory with none of the shapes is refused by name. (#4440)
