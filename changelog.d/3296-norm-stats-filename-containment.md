### Fixed

- **policies/lerobot_local**: the `norm_stats_filename` a checkpoint's `config.json` declares must now name a file inside the checkpoint. It was coerced with `str()` and joined onto the checkpoint directory, so a `..` segment stepped out of it and an absolute path discarded the directory entirely - the statistics that unnormalize every predicted action could therefore come from a JSON file the checkpoint does not contain, while its own `norm_stats.json` sat unread beside it, under a `load_norm_stats` call that reported success. On the shipped MolmoAct2 SO-100/101 fixture that is a 375.7 degree divergence on one action. An escaping or non-string name now raises `NormStatsFilenameError` naming the value and the `config.json` that declared it, the `filename=` argument is held to the same rule, and the reason reaches the load report in place of the generic missing-postprocessor message.
