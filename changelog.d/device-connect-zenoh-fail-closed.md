### Fixed:
- `Robot().run()` no longer comes online in plaintext by default. `device_connect_edge` validates transport security only for NATS, so on the default `zenoh` backend a fresh install with no credentials was reachable on the LAN unencrypted and unauthenticated - an anonymous peer could `execute` and `stop` it - while the code believed it was secure and logged no INSECURE warning. `init_device_connect` now refuses to start unless TLS is configured (`MESSAGING_CREDENTIALS_FILE`, TLS file variables, or a `tls/`/`quic/` endpoint) or the operator opts in with `DEVICE_CONNECT_ALLOW_INSECURE=true`; the message names both paths and `DEVICE_CONNECT_RPC_ALLOW`.
