### Fixed: the `rl` policy's task envelope now says the instruction was never read

`RLCheckpointPolicy` always documented `instruction` as ignored - the actor was trained against a reward function, not language - but it left `Policy.reads_instruction` at the `True` default, so `run_policy(policy_provider="rl", instruction="pick up the red cube")` answered `RLCheckpointPolicy | pick up the red cube` / `Policy complete` and an agent read that as a pick that happened. The class now declares `reads_instruction = False` with `instruction_free_actions` naming the trained actor's per-step commands, so the simulation and hardware envelopes append the same `Note: RLCheckpointPolicy does not read the instruction.` sentence the mock earns, and the JSON payload reports `instruction_read: false`. `docs/policies/rl.md` says so beside the sentence that already called the instruction ignored.
