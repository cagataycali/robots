### Docs: the API reference states each symbol, not each owning page's contract

`docs/api-reference.md` is a symbol index, but a dozen of its table cells had
grown from naming a symbol into restating the contract its owning page already
holds - why an unrecognized `list_robots` mode raises rather than widening, the
whitespace fold behind a `category` group, the filesystem-timestamp reason
`user_registry_source` returns bytes, and `stop_policy`'s four-way json verdict
walked through case by case. Each cell now states what the symbol is and its
value domain. Every signature span, refusal, value domain and environment
variable stays, the page is 1,481 words rather than 1,752, and it is graded by
the 1,500-word budget rather than named as owing a cut.
