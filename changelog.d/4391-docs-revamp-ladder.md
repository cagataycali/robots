### Docs: the site teaches the architecture, not the API

Start is a ladder of rungs (See it, Install, Run it, Talk to it, Real arm, Same checkpoint, Teach it, Fleet, Doctor), each ending in a checkpoint sentence and the first four carrying proof captured before the prose: a real agent transcript with a gate refusal and an approval, MuJoCo frames rendered from the page's own fence, and a flagship page that runs lerobot/smolvla_base in the simulator through the same run_policy call the hardware Robot takes. A Concepts tab explains the Policy -> Robot -> Backend spine with a glossary. Ten drawings are scene modules rendered in the site's own tokens (a grader refuses a stale SVG), Mermaid fences read the same tokens at render time, and code fences show a mono chip instead of a filename tab. Twelve wrong claims found on the way were fixed (act/observe, the gate sentence, serial ports on DDS robots, front-matter YAML on seven pages, mock=True). The site word ceiling moves to 55,319 for the new pages; pictures cost one word each.
