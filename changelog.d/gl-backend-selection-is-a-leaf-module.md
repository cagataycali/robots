### Fixed:

`import strands_robots` no longer has to import the simulation package to set `MUJOCO_GL`. The selection helpers (`_configure_gl_backend` and the doctor's vocabulary) moved from `strands_robots.simulation.mujoco.backend` to the stdlib-only leaf `strands_robots._mujoco_gl`; `backend` re-exports every name. Reaching `backend` ran `simulation/__init__.py`, whose eager imports loaded the simulation package on every import in a `[sim-mujoco]` environment. Measured on Linux x86_64 with `[all]` extras (`sys.modules` after `import strands_robots`): main 15 simulation / 52 package modules; this change alone 13 / 51 (the other eager chain, `policies.cosmos3.sim_ik`, is fixed separately); both together 0 / 26.
