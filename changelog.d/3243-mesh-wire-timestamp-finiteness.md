### Fixed

- Presence, the teleop input stream, remote E-stop and remote resume now refuse a wire timestamp that is not a finite number, instead of only one that is not numeric. All four handlers decide whether to act on an envelope by computing `now - t` and comparing the result against a freshness window and a forward-skew allowance, and all four gated the read on `isinstance(value, (int, float))` alone - which `nan` satisfies, being a `float`, before satisfying neither age test, since every comparison against a `nan` is False. `json.loads` accepts the bare `NaN` token by default, so the value arrives from the wire: a captured teleop stream replayed with `t` rewritten to `NaN` was applied in full at any later date, by the guard whose own comment names that replay as the threat it exists to stop; a replayed presence heartbeat registered a phantom peer; a replayed E-stop envelope engaged a fleet lockout; and on resume, where the HMAC binds `t` and `json.dumps` writes `NaN` for it, one signed envelope lifted a lockout for as long as it was replayed. `+/-inf` was already refused at all four, as future and as stale respectively, which is why a type-only gate looked sufficient. The rule now has one owner, `mesh.security.as_wire_timestamp`, which is the finiteness rule `mesh.core._parse_positive_float_env` already applied to the *other* operand of those same comparisons - the window - where a non-finite value, as `tests/mesh/test_env_float_knobs_reject_non_finite.py` puts it, "does not widen the bound but removes it". It returns the value as it arrived rather than coercing to `float`, because widening an integer stamp would change what the resume MAC verifies, and it excludes `bool`, which the E-stop and resume gates had read as one second past the epoch. Every existing refusal message is unchanged. Pinned by `tests/mesh/test_wire_timestamp_must_be_finite.py`, which grades all four surfaces against the three non-finite values in both their Python and their JSON-token spellings with a fresh-still-acts and a stale-still-refused control on each, and derives the graded population from the package so a fifth handler is graded when it lands; 6 of its 38 cells fail with the gates as they were and the remaining 32 pass on both trees.
