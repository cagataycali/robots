### Tests: ten domain suites check every surface of one value in one cell

The Kimodo sampler knobs, the lerobot tokenizer budget, the microduck velocity
gate, the policy handshake rates and delays, the environment-map resolution and
clip planes, the gsplat panorama bake, the Isaac parallel-env count, the Newton
viewer port and the benchmark string fields each split one refused value across
two to eight cells, one per thing that refusal must also be true of (the
message names the parameter, the second surface agrees, nothing was spent).
Each value now gets one cell that asserts all of them. The value tables are
unchanged. The ten files go from 985 cells to 448 with the same package lines
executed.
