## Decision: mkdocstrings, static

`PYTHONPATH=. .venv-docs/bin/python -c "import strands_robots"` succeeds, but `strands_robots.simulation` fails on numpy and `tools.use_lerobot` / `mesh` fail on `strands`. It does not matter: mkdocstrings-python 2.x uses griffe's static analysis, so with `allow_inspection: false` and `paths: ["."]` every `:::` directive renders from source without importing. Verified: all 8 API pages build under `--strict` in `.venv-docs`, 1.4 s.

Griffe emits parser warnings on a handful of source docstrings (`audit.py:1039` Raises section prose, `gr00t_inference.py:1124` indentation, missing `**kwargs` annotations). They would fail `--strict`; the plugin block below silences them with `docstring_options.warnings: false`. The alternative is fixing six docstrings in `strands_robots/`, which no docs lane may do; a follow-up PR could.
