# WBC per-call command override domains

`wbc_command_override_domains.png` is generated by `capture.py` (run once per
tree) + `compose.py`. Real Unitree G1, real `GR00T-WholeBodyControl-Balance.onnx`
weights, headless MuJoCo (`MUJOCO_GL=egl`), 200 ticks at 50 Hz.

`facts_main.json` / `facts_branch.json` are the two measured runs; every number
in the figure is read from them, and `compose.py` asserts each one plus that the
two runs came from different source trees.
