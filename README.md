# Artifact: the client reseed's seed domain

`reseed_seed_domain.png` is generated by these two scripts, nothing is hand-typed.

* `measure_reseed.py` - run inside the tree being measured (it prints the tree it
  resolved, so a before/after pair is provably two different trees). Drives
  `reseed_client_rngs` as a provider's `reset` does and records, per seed,
  whether each global RNG moved, plus two identically-seeded "episodes" of draws
  from both streams.
* `compose_figure.py` - reads the two JSON dumps and asserts every claim the
  figure makes before saving, including the half-seeded counts and a clean
  8-pixel border.

Measured on `upstream/main` @ `a72ac3bb` versus the change.
