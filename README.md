# torch stand-in: serve-or-skip contract

`torch_stand_in_contract.png` is generated by `make_figure.py`, which re-parses the
four pytest logs it names and asserts every number it renders before saving.

`blocktorch.py` is the pytest plugin used to produce a faithful torch-less
environment: a MetaPathFinder that refuses `torch` before any conftest is
imported, so `conftest` installs the stand-in exactly as it would on a machine
without the `[all]` extra.

    PYTHONPATH=. python -m pytest -p blocktorch tests -q --continue-on-collection-errors
