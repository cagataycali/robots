# Artifact: teleop posture-flag domain

`flag_domain.png` is generated by `compose.py` from two runs of `capture.py` -
one in a `git worktree` at `upstream/main`, one on the branch. Each dump records
the tree it imported from, and `compose.py` asserts the two differ plus every
number the figure states (12 of 12 inverted cells before, 0 after; the honored
argv byte-identical across trees).
